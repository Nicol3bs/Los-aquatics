# PYTHON AQUARIUM — PA1
    A Programming Assignment for CIIC 3015

## 📌 Overview
Welcome to PA1!
This programming assignment introduces students to fundamental control flow logic and modular design through the creation of a visual fish tank using Python Turtle graphics. The goal of this assignment is to help students become comfortable with `for` and `while` loops, conditional `if/elif/else` statements, the modulus operator, and writing custom functions with detailed docstrings.

## 🐟 Program Description
This program is a customizable aquarium generator built using Python's standard `turtle` library (and optionally `svg_turtle` for high-quality image exports). The program draws the walls of a fish tank, populates it with ascending bubbles and seaweed, and spawns custom sea creatures based on specific boolean traits (like whether a creature is facing left or right).

The project is designed to solidify algorithmic thinking. Students are guided through the code with TODO comments that focus on fixing broken loop constraints, implementing alternating logic with the modulus operator, and architecting their own drawing functions from scratch. This assignment emphasizes building clean, parameterized functions and correctly routing logic through a central dispatcher.
